## Descripción General

Este proyecto implementa una Galería de Arte inmersiva que recrea un ambiente estilo backrooms con personajes animados. El programa permite al usuario navegar libremente por el entorno utilizando controles de cámara en primera persona, observar animaciones de personajes en tiempo real y controlar la reproducción de audio ambiental.
